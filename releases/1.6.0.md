# CitconPay Gateway for WooCommerce v1.6.0 Release Notes

**Minimum Requirements:**
- PHP: 8.2 or higher
- WooCommerce: 9.7.1 or higher

---

## Highlights

- 🚀 **Full support for WooCommerce Blocks & Classic Checkout**: Unified structure, style, and experience for all payment methods.
- 💳 **New: Credit/Debit Card support** (Visa, MasterCard, Amex, Discover) with multi-icon display and wide currency coverage.
- 🎨 **Consistent UI**: All payment methods use flex layout, no line breaks, and are fully responsive.
- 🔄 **Vendor data flow closed loop**: Accurate vendor field submission and processing on both checkout types.
- ⚙️ **Flexible configuration**: Easily set default method, icons, enable/disable, and more in admin.
- 🛠️ **Modern codebase**: Refactored JS/PHP, all styles via CSS classes, improved documentation, and ready for WooCommerce 9.7.1+ / PHP 8.2+.
